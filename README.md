# 製造業向け基幹システム UIデモ（Windows onedir版）

製造業の基幹業務を題材に、データ入力、検索、一覧表、CSV入出力、MRP、グラフ、帳票、工場可視化などの画面・操作を確認できるWindows向けデスクトップデモです。

> [!IMPORTANT]
> 本アプリは、クラウドワークス等で開発実績・UI設計・データ処理の例を提示するための**デモ作品**です。入出力、表、グラフ、画面遷移などの確認を目的としており、実在企業の業務データや本番運用を想定した完成品ではありません。業務判断、会計、在庫確定、生産指示、セキュリティ検証済みシステムとして使用しないでください。

## デモで確認できる内容

- 品番、会社、工程、工順、品番構成などのマスタ入力・検索
- 受注、出荷、生産実績、外注受入、入出庫、在庫、棚卸などのデータ表示・入力
- MRP対象品番の検索、所要量計算結果、推移表・グラフ表示
- 一覧表の絞り込み、並び替え、列表示設定
- CSVデータの取込み、プレビュー、出力設定
- 集計表、レポート、グラフなどの可視化
- 作業実績入力、ワーキングデータ表示、実績分析
- 工場レイアウトと設備・進捗状況のViewer表示
- WindowsデスクトップアプリからローカルWeb画面を起動する構成

詳しい仕様は[仕様概要](docs/SPECIFICATION.md)をご覧ください。

## サンプルデータ

初回起動時、対象データが存在しない場合だけ、デモ用の業務データを自動生成します。

- 基幹業務サンプル: 54テーブル、合計1,057行
- MRP予測: 起動月の1日から3か月分
- 出荷予測数量: 製品ごとの日当出荷数を平均値とし、日ごとの数量を±2σ以内で生成
- σ: 日当出荷数の10%（最低1個）
- 既存データがあるテーブルは上書きしません

すべて架空のデモデータです。実在する会社、人物、品番、取引、製造実績とは関係ありません。

## 動作環境

- Windows 10 / 11（64bit）
- 約2GB以上の空き容量を推奨
- ローカルTCPポート `8000` を使用
- インストール不要のonedir形式

## ダウンロードと起動

1. このリポジトリの **Releases** から最新のZIPをダウンロードします。
2. ZIPを任意のフォルダへ展開します。
3. `desktop_company_mainsystem.exe` を起動します。
4. ログイン画面では、デモ用の初期アカウントを使用します。

```text
ユーザー名: 1
パスワード: 1
```

初回起動ではローカルDBとサンプルデータを作成するため、画面表示まで少し時間がかかる場合があります。Windows Defender等の確認画面が表示された場合は、内容を確認してから実行してください。

## データの保存場所

実行後のDB、ログ、設定、バックアップ等は、展開先の `runtime_companies` 以下へ作成されます。デモを初期状態に戻したい場合は、アプリを終了してからこの実行時フォルダを別の場所へ退避してください。

- 初期アカウントはデモ用の簡易認証です。本番環境では使用できません。
- 本番利用に必要な権限設計、監査、負荷試験、障害対策、バックアップ運用、法令・会計要件への適合確認は行っていません。

- 実データ、個人情報、顧客情報、機密情報を入力しないでください。
- 本デモを使用して生じた業務上・金銭上その他の判断や損害について、作者は責任を負いません。
