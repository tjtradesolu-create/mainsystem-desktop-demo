# v0.1.0-demo

製造業向け基幹システムのWindows onedirデモ初回公開版です。

## 起動方法

1. `mainsystem-desktop-demo-windows-x64-v0.1.0.zip` をダウンロードして展開します。
2. `desktop_company_mainsystem.exe` を起動します。
3. ユーザー名 `1`、パスワード `1` でログインします。

初回起動時には、ローカルDB、基幹業務のサンプルデータ、起動月初から3か月分のMRP予測データを自動生成します。

## 注意事項

本アプリは、入出力、表、グラフ、MRP、画面遷移などを確認するポートフォリオ用デモです。実データを入力せず、ローカルPC上だけでお試しください。本番業務、会計処理、在庫確定、生産指示、インターネット公開には使用できません。
