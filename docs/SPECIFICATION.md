# 仕様概要

## 1. 目的

製造業の基幹業務を題材として、マスタ管理、日常入力、検索、在庫・所要量の可視化、帳票・グラフ表示を1つのデスクトップアプリ内で体験できるデモを提供します。

本書は公開デモの概要であり、本番システムの要件定義書、動作保証書、会計・生産管理規程ではありません。

## 2. アプリ構成

Windows実行ファイルがローカルWebサーバーを起動し、同梱のWeb画面をデスクトップウィンドウ内に表示します。標準の起動ポートは `8000` です。業務データはローカルのSQLiteへ保存します。

## 3. 主な機能領域

| 領域 | デモ内容 |
|---|---|
| 共通マスタ | 会社、品番、工程、工順、品番構成、ロケーション等の入力・検索 |
| 受注・出荷 | 受注情報、出荷予定・実績、履歴の一覧表示 |
| 生産・外注 | 生産実績、作業実績、外注受入等の入力・確認 |
| 在庫・棚卸 | 入出庫、在庫照会、棚卸明細、CSV退避・取込みの画面例 |
| MRP | 品番・工順の選択、所要量計算、日別推移の表・グラフ表示 |
| レポート | データ項目を使った一覧・集計・グラフ表示の例 |
| データ連携 | CSV取込み、出力項目設定、プレビュー、データ出力 |
| 現場表示 | 工場レイアウト、設備、作業進捗を視覚的に確認するViewer |

## 4. サンプルデータ生成

アプリの起動後、対象の業務テーブルが空の場合に限り、同梱JSONから架空のサンプルデータを補完します。既にデータがあるテーブルは変更しません。

MRP予測は、起動した月の初日を開始日として3か月分を生成します。各製品の日当出荷数を平均値、日当出荷数の10%（最低1個）をσとして、毎日の数量を平均±2σの範囲に収めます。

## 5. 非機能面の位置づけ

- 単一PCでのローカルデモを想定
- 初期ログインはデモ用簡易アカウント
- サンプルデータは説明・画面確認用
- 本番相当の同時接続、可用性、監査、性能、セキュリティ試験は対象外
- 外部公開サーバー、正式な基幹DB、会計確定処理としての利用は対象外

## 6. デモ上の制限

- 業務ルールや計算式は画面説明用に簡略化している箇所があります。
- 全画面・全操作を本番品質として保証するものではありません。
- データの永続性や移行互換性は製品版仕様として確約していません。
- 実際の導入には、業務分析、要件定義、権限設計、移行、試験、運用設計が別途必要です。
